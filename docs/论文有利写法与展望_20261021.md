# 论文有利写法与展望（基于已有实验结果，2026-10-21）

> 原则：不编造、不隐瞒。把所有"能站住的结论"放到最显眼的位置，把"站不住的
> 强主张"改成可辩护的弱主张或机理分析，把"没做的"写进展望。三种子实验不是
> 减分项——它把论文从"单次运气"变成"有统计支撑的结论"，审稿人会认这一点。

---

## 一、全文叙事怎么调

原稿的主线是"RST 最好 → 共享表示有干扰 → DEDF 兑现增益"。三种子结果要求
改成一条更稳的主线：

> **"组织信息（RST 框架）→ 保障编码（取景扰动增强，稳定 +3.2）→ 融合决策
> （DEDF：与种子集成同等精度、但专家可解释可并行；并系统归因了增益来源）"**

- 把**训练增强**从"第三个创新点"提升为**最硬的实证贡献**（+3.20±0.37，
  三种子全正，CLIP 上复现）；
- 把 **RST 框架**定位为"信息组织与机制分析"贡献，场景增益写"三种子方向
  一致、且集中在机制预测的位置"，不写"大幅提升"；
- 把 **DEDF** 定位为"可解释、模块化、可并行的解耦决策融合范式"，并主动
  报告"等模型数下与种子集成精度相当"这一发现——这是**方法论贡献**，
  不是失败；
- 把**单模型模态排序不稳、hard/diff 无效、等规模 9v9 未做**全部写进局限。

### 2.4 DEDF：把"打平"写成方法论发现

| 证据 | 数字 |
|---|---|
| 逐种子 DEDF | 93.64 / 93.34 / 92.74 → **93.24±0.46** |
| 对同种子 RS | +1.97 / +2.23 / +1.47（每个 p<0.001） |
| 低置信子集（vs RO） | **+9.09，p<1e-5** |
| 等模型数 vs RS 种子集成 | +0.33（p=0.343，打平） |
| 9 专家异构集成 | **93.97**，较 RS 种子集成 +0.67（p=0.019，9 vs 3） |
| 同监督 DEDF | 93.17，仍比单 RS +2.13（p<1e-8） |
| 宽融合头单模型 | 90.77（−0.90，p=0.064，容量不是来源） |
| Oracle / 分歧率 | 95.64 / 9.1%（与种子集成 95.84 / 9.6% 相当） |

**可写的三条有利结论**：
1. **聚合本身稳定有效**：每个随机种子下 DEDF 都显著优于同种子单模型
   （+1.47~+2.23，全部 p<0.001），三种子均值 93.24±0.46；
2. **增益不是监督差异或宽度造成的**：同监督 DEDF 仍 +2.13；宽头单模型
   无增益；温度缩放/学习权重都不如等权 logits（93.14/93.07 vs 93.54）；
3. **异构集成在规模化后有额外收益**：9 专家 93.97，比同模态 3 种子集成
   高 0.67（p=0.019）；同时 DEDF 提供**可解释的专家分工**与**模块化并行**，
   这是 seed-ensemble 不具备的。

**建议措辞（这段是全稿最关键的改写）**：
> "三种子实验表明，DEDF 相对同种子单模型的增益稳定显著（+1.89±0.39，
> 每个种子 p<0.001）。进一步对照发现，在等模型数（3 个）下，DEDF
> （93.24±0.46）与最强单模型的三种子集成（93.30）精度统计等价
> （+0.33，p=0.343）；同监督、宽融合头、温度缩放与学习权重等对照排除了
> 监督配置、模型宽度与校准误差作为增益来源。这表明决策级融合的主要收益
> 来自集成多样性；当扩展到 9 个专家时，异构集成达到 93.97%，较单模态
> 种子集成高 0.67 个百分点（p=0.019）。DEDF 因此被定位为一种**可解释、
> 模块化、可并行**的解耦融合范式：它以与种子集成相当的算力获得同等精度，
> 同时给出可解释的专家分工（场景修正/语义补位/全模态），并在此规模上
> 获得小幅但显著的异质性增益。"

**这段的妙处**：主动承认"等算力打平"，把审稿人的质疑变成你的发现；
同时用 9 专家的 +0.67 保住"异质有额外增益"的小主张，并标注 9 vs 3 的
口径限制。审稿人最反感的是隐瞒，不是负结果。

## 五、局限与展望（逐条写进第 5 章，对应审稿人）

1. **DEDF 的等算力定位**：在等模型数（3×）下与同模态种子集成精度相当
   （93.24 vs 93.30，p=0.343），模态异质性的净增益仅在 9 专家规模下观察
   且模型数不等。未来工作：**9 vs 9 等规模对照**、单模型 MoE/蒸馏，把
   决策级互补迁移到 1× 推理成本。
2. **RST 模态增益的稳健性**：场景增益三种子方向一致但均值仅 +0.71；
   RT 在一个种子上为负；单模型最优配置随损失配方漂移（完整配方 RS 最优，
   统一监督 RST 最优）。未来：更多种子、更大视觉底座、更强的场景编码、
   配方与模态的联合搜索。
3. **自适应语义融合仅单种子验证**：+1.03（p=0.022）来自 seed0，未来需
   多种子确认；few-shot 的 +3.22 也建议扩展种子。
4. **hard/diff 项无测试增益**：RST_full（90.95±0.22）低于同监督 RST
   （91.77，单种子）；未来应移除或重新加权监督项。
5. **单数据集、单划分**：仅用该数据集的官方图像级划分；未做跨库
   （FGVC-Aircraft、MAR20）与 5 折交叉验证；建议未来补近重复审计、
   跨库冻结探针与 5 折。
6. **3 倍推理成本与部署**：DEDF 识别耗时 2.9×；三卡并行可恢复吞吐，
   但未在真实流水线实测；未来做蒸馏、路由与并行调度。
7. **开放集与稀有类**：仅验证闭集 114 类；稀有类与未见型号未覆盖。
8. **对比方法边界**：MLLM 仅 Qwen3-VL 直推，未做 BLIP-2/LLaVA 微调；
   跨架构比较受限。
9. **TTA 未纳入**：评测使用索引缓存的裁剪几何，多尺度 TTA 需在裁剪层
   重实现，留待未来。

- RST：91.77 vs 91.14（+0.63，p=0.169）
- RT：90.97 vs 91.51（−0.53，p=0.282）
- DEDF：93.50 vs 93.64（−0.13，p=0.749）

**结论：困难负样本、对比项、属性项都没有一致的正向证据，三个方向甚至相反；
差异全部落在重跑噪声内（RS 与 RS_nosup 同配置重跑差 0.63，9.7% 预测翻转）。
所以"没有用"可以成立为"未观察到显著增益"，但不能写成"证明有害"。**

### 8.2 两个必须纠正的表述

1. **"统一监督下 RST > RS" 只有 +0.10（p=0.88），不是 +0.73。**
   +0.73 是 `RST_nosup` 对 `RS_nosup`（91.04）；`RS_nosup` 与 `RS` 是同一
   监督配置的重跑，后者 91.67，故正确对比是 RST 91.77 vs RS 91.67。论文
   应写"RST 与 RS 并列最优，差异不显著"，不能写"RST 优于 RS"。
2. **"统一监督下 RT > R" 只有 +0.33（p=0.52），不显著。**
   完整配方下 RT 的 +0.87 部分来自 con/hard/diff 监督；删掉后文本增益
   会明显缩水。这是删除的主要代价。

### 8.3 删不删：两种方案

**方案 1（推荐，若接受单种子限制）：删除，统一为 dom+cls**
- 方法节：损失改为 L_dom + L_cls；删除 L_con、L_hard（含 hard table 挖掘、
  margin/τ_m）、L_diff（属性矩阵、属性头）；三阶段课程改为两阶段
  （S1 仅 Region 10 epoch；S2 +Scene+Text 15–20 epoch）；表 4-1 同步删参数。
- 表 4-3 换成 8.1 的表：R 90.64 < RT 90.97 < RS 91.67 < RST 91.77，
  顺序正好符合原目标；RST−R 显著（+1.13，p=0.014）。
- 表 4-4 换成统一监督 DEDF 93.50（双专家 92.67/93.00/93.24），
  full 配方 93.64 作为附录/脚注（p=0.75，无差异）。
- 收益：专家间**只剩模态差异**，审稿人指出的"损失配置混淆"彻底消失；
  训练流程、知识库、复现负担大幅简化；RST 成为最优单模型。
- 代价：RT/RST/DEDF 统一监督只有 seed0；文本增益缩到 +0.33（n.s.）；
  三种子 DEDF（93.24±0.46）是完整配方的，需注明"配方无关的稳健性"。

**方案 2（保守，保留三种子主证据）：方法不改，只删贡献表述**
- 主表仍用完整配方（93.64/91.14 等），三种子证据完整；
- 把 hard/diff 从创新点与"方法必要性"里删掉，新增"可选损失消融"：
  DEDF 93.50 vs 93.64（p=0.75）、RST 91.77 vs 91.14（p=0.17），
  说明这些项"无显著增益，可安全移除"；
- 缺点：主表仍存在 RST<RS 与监督混淆，需要额外解释。

**建议**：如果目标是"顺序好看 + 方法简单 + 消除审稿人的监督混淆"，
选方案 1；如果目标是"三种子证据完整、少改表"，选方案 2。
考虑到你已决定不再补种子，方案 1 的单种子限制需要在局限里明写一句：
"统一监督下 RT/RST/DEDF 的多种子验证留待后续"。
