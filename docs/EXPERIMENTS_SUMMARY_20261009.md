## 4. Text 机制改进系列（Route-C，逐机制单变量检验）

对照基线：**旧 R+T = v2_rt_f_s0（90.47/88.74）**、**Region-only = v2_ro_s0（90.64/88.93）**

| 机制 | 描述 | Top-1 | Macro-F1 | vs 旧RT (McNemar) | 判定 |
|---|---|---|---|---|---|
| `--proto-head` | 分类头权重=原型池化投影（文本必经路径） | 90.81 | 89.52 | +0.34/+0.78，p=0.50 | 不显著 |
| **`--adaptive-sem`** | **logits=(1−w)·视觉+w·S_c，w 学自置信度** | **91.51** | 89.30 | **+1.04，p=0.022 ✓** | **成立** |
| `--adaptive-sem --con-detach` | 对比项 stop-gradient 视觉侧 | 91.04 | 89.32 | −0.47，p=0.33 | 无增益 |
| `--adaptive-sem` + 成对差异句 KB | Qwen3-VL 对真实混淆对生成 146 条差异句 | 91.24 | **89.44** | −0.27，p=0.58 | 无整体增益 |

**adaptive 的机制证据**（与设计假设完全一致）：
- 低置信子集（conf:low，n=1001）**+4.3 点**；<64px 小目标 **+4.4 点**
- 对 Region-only 净 +0.87（p=0.065）；Top-1 达到 91.51（无 Scene 条件下）
- 语义头（S_c）的推理贡献从旧机制的 +0.64 提升到自适应融合下的结构性组成部分

## 6. 低资源（few-shot）实验

每类训练样本截取 K 个（固定种子 12345，同 K 档三配置共享同一子集）：

| 配置 | 全量 | K=10 | K=5 |
|---|---|---|---|
| Region Only | 90.64 / 88.93 | 51.03 / 47.37 | 38.41 / 34.22 |
| Region+Text | 90.47 / 88.74 | 50.47 / 47.88 | 37.74 / 34.88 |
| R+Scene+Text | 91.14 / 88.70 | 48.07 / 45.99 | 36.21 / 33.67 |
| **S_c 语义头贡献（RT / RST）** | +0.64 / −0.50 | **+1.55 / +3.22** | **+2.13 / +2.93** |

**结论**：① RT−R 整体差在各 K 档均不显著（p>0.39）；② **S_c 语义头的贡献随监督稀缺单调上升**
（+0.6→+3.2）——文本知识的价值在低资源下的证据；③ stage-3 困难机制在低资源下**显著有害**
（K=10 −2.40，p=0.001；K=5 −1.53，p=0.041）。
数据-性能曲线：CLIP-L 零样本 35.68 → K=5 38.41 → K=10 51.03 → 全量 90.64。

## 8. 诊断与统计基础（所有结论的支撑）

- **噪声地板 2.05 Macro-F1 点**（4 次同配置重复的极差）——单种子 <1 点差异不作为结论；
- **文本塔塌缩诊断**：SigLIP2 类名嵌入两两余弦 0.97、零样本 ≈ 随机（1.23% vs 0.88%）；
  图像侧冻结特征 1-NN 44.77% 正常 → 塌缩在文本侧；
- **S_c 贡献的测量方式**：同一次前向的 with/without_semantic 差（配对）；
- **尺寸分层**：本模型峰值在 128-256px（Top-1 ~92-95），向两端衰减；Scene 的增益集中
  在 <64px~128px；adaptive 的增益集中在 conf:low 与 <64px；
- 大目标（≥384px，占 50.8%）比峰值低 4-6 点：推理期多视角与 512 输入两个补救探针均为
  负面结果（−1.2~−4.8），需以更高分辨率从头训练才可能解决。

## 9. 融合层级与模态组合分析（SigLIP2 微调特征，2026-10-09 补）

同一份微调 SigLIP2 特征（来自 v2_rs_s0 检查点：region 池化 768 维 / scene 池化 768 维 /
文本类原型），三种融合层级 × 四种模态组合：

| 融合层级 | R | RS | RT | RST |
|---|---|---|---|---|
| 特征级（拼接+MLP） | 89.44 / 87.85 | 89.94 / 87.98 | 89.17 / 87.09 | 89.77 / 87.86 |
| 特征级（拼接+线性） | 89.77 / 87.47 | 89.87 / 87.62 | 89.84 / 87.55 | 89.81 / 87.12 |
| 交互级（RST 系统） | 90.64 / 88.93 | **91.67 / 89.74** | 91.51 / 89.30\* | 91.14 / 88.70 |
| 决策级（单模态专家聚合） | 89.44 / 87.85 | **90.74 / 88.25** | 88.87 / 86.15† | 90.01 / 87.94 |

\* 交互级 RT 用 adaptive 机制；† 决策级 RT 为等权平均（被弱专家拖累，未调优）。

单模态专家独立读数：**E_R 89.44 / E_S 50.50 / E_T 84.41**（决策级特有）。

**结论**：① 场景（S）的净增益随融合层级系统性递增——特征级 +0.50 → 交互级 +1.03（p=0.036）
→ 决策级 +1.30；② 模态独立能力不对称（场景整图仅 50.5%、区域-语义匹配 84.4%）解释了
S 必须依托交互/决策修正、T 本身即强判别依据；③ 特征级融合下四组合差异 ≤0.5，简单拼接
无法兑现互补性。

## 10. 解耦专家决策融合（DEDF，2026-10-09 补）

方法：场景上下文专家（R+S）+ 类别语义专家（R+T，adaptive）+ 全模态专家（R+S+T）
独立训练，决策级等权聚合（无拟合参数、零训练成本）。

| 配置 | Top-1 | Top-5 | Macro-F1 |
|---|---|---|---|
| 最优单模型（R+S） | 91.67 | 97.30 | 89.74 |
| R+S + R+T | 92.90 | 97.57 | 91.40 |
| R+T + R+S+T | 92.87 | 97.30 | 91.36 |
| R+S + R+S+T | 92.77 | 97.70 | 90.94 |
| **三专家聚合（DEDF）** | **93.64** | **97.80** | **92.15** |

对照：纯 SigLIP2 微调（R）90.64 / 88.93；RST 单模型三模态 91.14 / 88.70。

**关键性质**：① 相对最优单模型 +1.97 / +2.41；② 与常规同构 ensemble 的区别是
**模态配置异质性**（错误互补），增益位置可预测（低置信样本、中小实体——与 4.4.4 的
模态能力分析一致）；③ 推理成本 2-3 倍、可并行，工程上可按预算在单模型与聚合间取舍；
④ 单模型内的机制化形式（双分支 MoE）未做，列为后续工作。
