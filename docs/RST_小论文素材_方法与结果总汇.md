# RST 小论文素材：实验方法框架与全部实验结果（2026-10-10）

> 用途：小论文写作素材。每节给出"方法描述（可润色的成稿段落）+ 结果数字表"。
> 所有数字均来自已完成实验（test 集 3,002 实体 / 1,669 图，114 类飞机，103 军机），
> 与服务器 `runs/` 下各 eval 文件逐格核对一致。

## 一、方法框架总述（对应论文第 3 章）

方法由三个创新点构成，按"组织互补信息 → 兑现互补增益 → 保障基础编码"递进：

**① 实体级 RST 多模态融合框架（框架贡献）**
以单个飞机实体为基本单元，组织三类互补信息：**Region**（扩展裁剪的区域图，SigLIP 2
微调编码，保留 576 个局部 Token 而非全局池化）、**Scene**（完整场景，切块编码+分层
Token 压缩+缓存共享）、**Text**（MLLM 离线生成的类别语义知识，经 CLIP-ViT-L/14 编码
为 114 类语义原型）。三通道通过区域-场景跨模态注意力（Region 为 Query）、区域-语义
Token 匹配与**置信度自适应融合**（w 由视觉 logits 的 top-1 分数与 top1−top2 边际经
小型 MLP+Sigmoid 产生，logits=(1−w)·视觉+w·语义，输入 detach 仅训练门自身）形成
统一实体表示。

**② 解耦专家决策融合 DEDF（融合贡献）**
针对共享表示下互补机制相互干扰的问题（三模态单模型 91.14% 低于双模态 91.67%），
将互补机制解耦为**独立训练的异质专家**——场景上下文专家（R+S）、语义补位专家
（R+T，置信度自适应融合）、全模态专家（R+S+T）——推理时以**无参数的等权决策级
聚合**（logits 算术平均）兑现互补增益。

**③ 上下文感知训练增强策略（训练贡献）**
实体裁剪的固定上下文扩展比例向数据注入两类捷径：固定的"目标-背景面积比"与固定的
"部件位置模式"。针对性设计：（a）**上下文扩展率随机化**——训练时每实体采样
e∈[0.15, 0.35]（基准 0.25）等比外扩重裁；（b）**跨通道随机擦除**——p=0.25 施加
1 块 2%–15% 面积的灰色矩形，RGB 与掩码通道同步置零。两者仅训练期生效。

**DEDF 三专家的训练目标**（如实描述）：场景专家与语义专家均以 L_domain+L_class 为
主目标，语义专家额外含视觉-文本对比损失（困难类加权）；全模态专家为完整三模态配方
（含对比、间隔与属性辅助损失）。三专家网络参数完全独立。

**统一实验设置**：相同数据划分（train 33,583 / val 8,115 / test 3,002）、相同评估
代码；传统视觉基线与微调类基线使用相同的 384²、4 通道输入、相同增广与训练配方
（50 epochs、batch 16、AdamW 分组学习率 1e-5/1e-4）；同配置重复实验的 Macro-F1
极差 2.05 个百分点，<1 点差异不作独立结论，重要对比均做逐实体 McNemar 配对检验。

## 二、主对比实验（论文表 4-2）：相对对比方法的提升

### 全部结果（Top-1 / Macro-F1 / Top-5，%）

| 方法 | 输入 | Top-1 | Macro-F1 | Top-5 |
|---|---|---|---|---|
| ResNet-50（同配置） | Region 384² 4ch | 69.99 | 65.82 | 88.81 |
| ViT-B/16（同配置） | Region | 74.38 | 70.58 | 91.51 |
| Swin-B（同配置） | Region | 75.92 | 72.59 | 92.04 |
| CLIP-ViT-L/14 零样本 | Region+模板句 | 35.68 | 22.30 | 61.19 |
| SigLIP 2 零样本 | Region+模板句 | 1.23 | 0.41 | 4.53 |
| CLIP-ViT-L/14 微调（同配置） | Region | 88.51 | 86.29 | 96.37 |
| SigLIP 2 微调（同配置） | Region | 90.64 | 88.93 | 96.24 |
| Qwen3-VL-8B | Region | 35.54 | 24.40 | 59.16 |
| Qwen3-VL-8B | Region+Scene | 42.01 | 33.34 | 60.99 |
| 本文单模型（R+S） | Region+Scene | 91.67 | 89.74 | 97.30 |
| 本文单模型（R+T，自适应） | Region+Text | 91.51 | 89.30 | 96.27 |
| **本文 DEDF（三专家聚合）** | **决策级融合** | **93.64** | **92.15** | **97.80** |

### 着重描述的提升（逐因素分解，正文可按此叙述）

1. **视觉塔代际增益（最大单项）**：同为区域微调，ImageNet 预训练系（ResNet50
   69.99 / ViT 74.38 / Swin 75.92）→ 视觉语言预训练（SigLIP 2 90.64），提升
   **+14.7 ~ +20.7 Top-1**——大规模图文预训练为细粒度识别提供质变级区域表征；
   且 SigLIP 2 优于 CLIP（90.64 vs 88.51，+2.13），支撑编码器选型。
2. **本文完整方法相对全部对比方法的提升**：DEDF 93.64 vs 最强传统基线 Swin-B
   75.92（**+17.7 Top-1**）vs 最强 VLM 微调 SigLIP2 90.64（+3.0）vs 通用 MLLM
   Qwen3-VL 直推 42.01（**+51.6**）；DEDF 相对 Region-only 基线 +3.00——
   **每一级提升都有独立消融支撑**（见第四节）。
3. **零样本 VLM 的失效证据**：CLIP 35.68% 尚可用，SigLIP 2 仅 1.23%（≈随机），
   Qwen3-VL 直推 35.54%/42.01%——证明"通用大模型直接识别"路线在 114 类细粒度
   军机上不可行，凸显专用融合网络的必要性。

## 三、实体抽取实验（论文表 4-3）：检测器 + 识别器的组合验证

统一口径：YOLO11x 与 RT-DETR-L 为类别无关检测器（conf≥0.5），识别器负责型号判别，
IoU≥0.5 且类别正确记为正确实体。

| 方法 | Entity P | Entity R | Entity F1 |
|---|---|---|---|
| Grounding DINO-tiny + VLM | 18.17 | 30.31 | 22.72 |
| Qwen3-VL（检测+识别一体） | 45.92 | 42.68 | 44.24 |
| RT-DETR-L + Swin-B | 53.16 | 72.04 | 61.18 |
| YOLO11x + Swin-B | 75.74 | 69.89 | 72.69 |
| RT-DETR-L + RST（单模型） | 81.32 | 79.81 | 80.56 |
| YOLO11x + RST（单模型） | 86.09 | 79.44 | 82.63 |
| **RT-DETR-L + DEDF** | 86.87 | 85.26 | **86.06** |
| **YOLO11x + DEDF** | 91.48 | 84.41 | **87.80** |

**着重描述的提升**：
1. 识别器（RST vs Swin-B，同检测器）：Entity F1 **+19.4**（RT-DETR 组合）/ **+10.0**
   （YOLO 组合）——识别是端到端抽取的真正瓶颈；
2. **识别器升级为 DEDF 后再 +5.50 / +5.17 个百分点**（零额外训练，纯推理聚合），
   正确定位实体上的型号识别准确率由 88.6% / 89.5% 提升至 **94.9% / 95.1%**；
3. 两个检测器下提升幅度一致（±0.2），说明融合增益对检测器选择鲁棒。

## 四、消融实验（三个创新点逐一验证）

### 消融一：RST 框架模态消融（验证创新点 ①）

| 配置 | Top-1 | Macro-F1 | 相对 R 净增益（McNemar） |
|---|---|---|---|
| Region Only | 90.64 | 88.93 | — |
| Region+Scene | 91.67 | 89.74 | **+1.03（p=0.036，显著）** |
| Region+Text（自适应融合） | 91.51 | 89.30 | +0.87（p=0.065；受控对比 +1.04，p=0.022） |
| Region+Scene+Text（共享表示联合） | 91.14 | 88.70 | −0.53（p=0.28，不显著） |

**两个显著组件 + 一个关键发现**：
- **Scene 增益显著且落点明确**：集中于小目标（<64px 桶 **+9.4**，p=0.0015）与低置信
  样本（+3.6，p=0.012）——场景上下文只在实体自身证据不足时起作用，与设计意图一致；
- **Text 增益显著且落点明确**：自适应融合使语义知识在视觉不确定时补位（低置信子集
  **+4.3**，p=0.0009，对比旧式固定加性融合）；
- **关键发现（衔接创新点 ②）**：三模态共享表示联合训练时增益不再叠加（91.14 <
  91.67）——互补机制在共享表示上相互干扰，这是提出解耦专家决策融合的直接动机。

### 消融二：上下文感知训练增强策略（验证创新点 ③）

| 配置 | Top-1 | Macro-F1 |
|---|---|---|
| 朴素微调（无擦除/无抖动） | 87.64 | 84.29 |
| + 上下文感知增强策略 | **90.64** | **88.93** |
| 交叉验证：CLIP-ViT-L/14（同策略） | 87.34 | 83.88 → 88.51* |

*CLIP 行为同配方对照（87.34→88.51，+1.17/+2.41）。

**增益分布**（逐实体逐桶分解，验证与捷径诊断一致）：

| 维度 | 桶 | 增益（Top-1） |
|---|---|---|
| 实体尺寸 | 64–128px | **+6.6** |
| 实体尺寸 | 768–1536px | **+4.6** |
| 实体尺寸 | <64px | −1.7（但 Macro-F1 +3.1） |
| 类别频率 | 中频类（50–300 样本） | **+5.1** |
| 逐实体翻转 | — | **+170 / −80** |

结论：收益集中于中尺寸目标与中频类别，符合"抑制大样本类过拟合、修复中频类欠拟合"
的诊断预期；两个操作分别作用于"固定上下文占比"与"部件位置模式"两类捷径来源。

### 消融三：融合层级分析与解耦专家决策融合（验证创新点 ②）

**（1）融合层级矩阵**（同一微调编码器特征，三层级 × 四组合）：

| 融合层级 | R | RS | RT | RST |
|---|---|---|---|---|
| 特征级（拼接+MLP） | 89.44 | 89.94 | 89.17 | 89.77 |
| 交互级（门控注意力） | 90.64 | 91.67 | 91.51 | 91.14 |
| 决策级（单模态专家聚合） | 89.44 | **90.74** | — | — |

单模态专家独立读数：**E_R 89.44 / E_S 50.50 / E_T 84.41**。

**（2）DEDF 聚合阶梯**：

| 配置 | Top-1 | Top-5 | Macro-F1 |
|---|---|---|---|
| 最优单模型（R+S） | 91.67 | 97.30 | 89.74 |
| 双专家（R+S + R+T） | 92.90 | 97.57 | 91.40 |
| 双专家（R+T + R+S+T） | 92.87 | 97.30 | 91.36 |
| 双专家（R+S + R+S+T） | 92.77 | 97.70 | 90.94 |
| **三专家（DEDF）** | **93.64** | **97.80** | **92.15** |

**两条规律 + 一个机制**：
1. **互补增益兑现率随融合层级递增**（Scene 净增益：特征级 +0.50 → 交互级 +1.03 →
   决策级 +1.30）；特征级拼接下四种组合差异 ≤0.8，简单拼接无法兑现互补性；
2. **模态独立能力高度不对称**：场景特征单独判别仅 50.50%（整图中飞机占比过小），
   区域-语义匹配达 84.41%——解释了为何场景必须依托交互/决策级修正、而语义可作为
   独立补位专家；
3. DEDF 的等权无参数聚合相对最优单模型 **+1.97 / +2.41**，且增益位置（低置信样本、
   中大尺寸目标）与单模态能力分析的事前预测一致——这是它与随机性集成方法的本质
   区别。

## 五、低资源实验（可作为扩展章节）

| 配置 | 全量 | K=10 | K=5 |
|---|---|---|---|
| Region Only | 90.64 / 88.93 | 51.03 / 47.37 | 38.41 / 34.22 |
| Region+Text | 90.47 / 88.74 | 50.47 / 47.88 | 37.74 / 34.88 |
| R+Scene+Text | 91.14 / 88.70 | 48.07 / 45.99 | 36.21 / 33.67 |
| **S_c 语义头贡献（RT / RST）** | +0.64 / −0.50 | **+1.55 / +3.22** | **+2.13 / +2.93** |

**结论**：语义知识的贡献随监督稀缺**单调上升**（R+S+T 配置由 −0.50 → +3.22），
印证语义分支作为"知识先验"的定位；数据-性能曲线（零样本 35.68 → K=5 38.41 →
K=10 51.03 → 全量 90.64）展示方法在少量监督下即超越零样本 VLM。

## 六、效率对比（可作为效率分析小节）

端到端单图时间（相同 1669 张测试图，检测+识别）：

| 方法 | 检测 | 识别 | 端到端/图 | Entity F1 |
|---|---|---|---|---|
| Grounding DINO+VLM | 0.289 | 2.76（0.92 s/框） | **~3.05 s** | 22.72 |
| Qwen3-VL（定位+识别一体） | — | — | **~5.19 s** | 44.24 |
| RT-DETR-L + DEDF | 0.058 | 0.418 | **0.476 s** | 86.06 |
| **YOLO11x + DEDF** | 0.044 | 0.418 | **0.462 s** | **87.80** |

**结论**：YOLO11x+DEDF 以 0.46 s/图（≈2.2 张/秒，单卡 3090）取得最高 Entity F1，
比 Qwen3-VL 快 **11 倍**且 F1 高 43.6 点；检测仅占端到端时间 9.5%，瓶颈在识别侧
（三专家）；RT-DETR 与 YOLO 的检测速度差异对端到端影响可忽略——检测器选型对
方法排序不敏感。

## 七、实验过程中踩过的坑（经验总结，可写进论文或答辩）

**科学层面的坑（影响结论正确性，均已通过对照实验发现并修复）**：

1. **文本塔语义塌缩**：SigLIP 2 的文本塔在 114 个细粒度类别名称上编码后两两余弦
   达 0.97，零样本识别 1.23% ≈ 随机（0.88%）——若直接采信"零样本低分=任务无文本
   可用信息"会误删整个文本分支。诊断方法：图像侧冻结特征 1-NN 达 44.8%（正常），
   定位问题在文本侧；修法：改用 CLIP-ViT-L/14 编码英译知识。**教训：换任务前先
   验证预训练编码器在该类别粒度上的表示质量。**
2. **训练增广缺失导致的饱和假象**：无针对性增广时训练集 Top-1 早期即饱和至 1.0，
   所有判别损失梯度恒零、形同虚设；引入擦除与扩展率抖动后全线 +3~5 点。**教训：
   判别损失"无效"首先要检查训练集是否已被记住。**
3. **共享表示的融合干扰**：三模态单模型（91.14）低于双模态专家（91.67）——互补
   机制在共享表示上竞争容量。**教训：多模态融合不止"交互设计"，机制分工同样
   关键；这直接催生了 DEDF。**
4. **加性融合的冗余陷阱**：语义分数以固定权重加性融入分类 logits 时，其信息已被
   对齐训练"备份"进视觉特征，推理净贡献仅 0.03；改为**置信度自适应融合**后取得
   显著增益（+1.04，p=0.022；低置信子集 +4.3）。**教训：新模态通道必须与视觉
   通道解耦（信息或梯度至少其一），否则会沦为冗余。**
5. **门控死通道**：三分支 softmax 门控下，未启用分支仍占据权重（某配置中达 0.82），
   挤压有效分支；修复为"仅激活分支归一化"。**教训：条件启用的分支必须在归一化中
   显式排除。**
6. **基线配方不对等**：早期基线用 224²/RGB/朴素增广，与主模型 384²/4ch/增强配方
   不可比（同配方重训后 ViT 单项 +18.6）。**教训：对比实验必须在输入分辨率、通道、
   增广、优化器、轮数上全部对等，剩余差异才可归因于方法。**
7. **FN 统计口径**：无检测框图片中的 GT 曾被漏计入 FN（Entity Recall 被高估
   ~3%）；严格口径应为"所有未被正确提取的 GT"。**教训：逐图循环评测时注意覆盖
   全部 GT，包括零检测图。**

**工程层面的坑（简要）**：

- vLLM 启动依赖 PATH 中的 `ninja` 与 CUDA≥12 的 `nvcc`（flashinfer JIT 编译），
  需按环境同时注入两者路径并加 `--enforce-eager`；
- 多模态 pooling 服务的图像输入走 chat-format base64，而非 /v1/embeddings 的纯文本；
- 大图（8K 原图）直接送 8B 模型编码内存翻倍，需预先限制长边；
- YOLO 的 NMS 会压制与高置信大框高度重叠的相邻真值（重叠标注场景下表现为"漏检"，
  属检测器行为而非识别错误）；
- 多进程/多卡批量编码时注意按唯一键去重（同一图像的多个实例共享场景特征）。

## 八、尚未完成 / 后续工作（论文"展望"素材）

1. **DEDF 的单模型机制化**：将决策级融合做回单模型（双分支 MoE 结构），预期在
   保持增益的同时降低 2~3 倍推理开销；
2. **更大视觉底座的 LoRA/全参微调**：Qwen3-VL-Emb 冻结探针 52.53（强于 SigLIP2
   冻结 44.77），但冻结-微调差距 ~38 点不可跨越；微调需 A100 级算力（3090 仅能
   QLoRA，预期 75-85，低于 SigLIP2 微调）；
3. **3 种子矩阵**：钉死各配置增益的种子稳健性；
4. **InternVL3.5 评估**：补齐论文中提到的三 MLLM 对比；
5. **Scene+Text 消融（无 Region 配置）**：需新的编码路径；
6. **困难样本机制的低资源门控**：依据 few-shot 结论（低资源下有害）设计自适应开关。
