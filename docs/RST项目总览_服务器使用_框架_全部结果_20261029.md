# 第二部分：实验框架完整描述

## 2.1 任务定义

输入一张任意尺寸的航空图像，输出图中**每架飞机的实体信息**：
边界框、型号（114 类，103 军机 + 11 民机）、军/民域、置信度。级联两阶段：
**类别无关检测**（只回答"哪里有飞机"）→ **细粒度识别**（回答"是哪一型、
军还是民"），避免检测器的类别先验干扰识别。

## 2.2 端到端数据流（从输入到输出）

```
输入图片 I（任意尺寸，最长边可达 8K）
   │
   ├─[1] 检测器 YOLO11x（单类 aircraft，imgsz 640，conf≥0.5）
   │      输出：N 个框 {b_i, s_i}
   │
   ├─[2] 逐框构造 Region 输入（与训练完全同几何）
   │      protected_box：以 0.25 等比外扩、裁到图内、扣除相邻检测框
   │      → 384×384、4 通道（RGB + 二值掩码）
   │      （推理固定 e=0.25；训练时 e~U(0.15,0.35) + 25% 概率跨通道擦除）
   │
   ├─[3] Scene 输入（每图一次，与框数无关）
   │      长边≤896：整图缩放；否则 448px 块、步长 336（≈25% 重叠）切块
   │      实体块保留 7×7=49 token，背景块压到 2×2=4 token，总预算 1024
   │      共享视觉塔编码（与 Region 同一个 SigLIP2，投影头独立）
   │
   ├─[4] 三个 RST 专家（各自独立训练的完整网络）
   │      E1 场景专家 R+S   ：激活区域-场景跨模态注意力
   │      E2 语义专家 R+T   ：激活区域-语义匹配 + 置信度自适应融合
   │      E3 全模态专家 R+S+T：完整三模态
   │      每个专家输出 114 维型号 logits + 2 维域 logits
   │
   └─[5] DEDF 聚合：三专家 logits 等权平均 → argmax
          输出：[{bbox, 型号, 军/民域, 置信度, 专家一致性} × N]
```

## 2.3 RST 单模型内部（每个专家的构成）

**Region 分支**：4 通道 384² → SigLIP2-base-patch16-384（微调）→ 24×24=576
patch token → 池化 12×12=144 token → 线性投影 h=768 + 二维正弦位置编码。

**Scene 分支**：切块后每块缩放 384² → 同一视觉塔（参数共享，投影独立）→
两级 token 预算（实体块 49 / 背景块 4）→ + 块级位置编码（含 near/far 身份）。

**Text 分支**：离线知识库（MLLM 生成 114 类描述/差异句，CLIP-ViT-L/14 冻结
编码为 114×6×768 原型，加可学习残差 ΔP，零初始化）。推理时只查表，不跑 MLLM。

**交互与融合**：
1. 区域-场景跨模态注意力：Region token 为 Query 在 Scene token 上检索
   （残差 + LN）→ F_RS；
2. 分支向量：z_R=池化(F_RS)；z_S=池化(环境视图，即剔除实体块后的场景
   token，避免与 z_R 同源)；z_T=池化(F_RS 对类无关语义记忆的查询结果)；
3. 动态门控：α = ε + (1-kε)·softmax_激活分支(gate[z_R;z_S;z_T])，ε=0.05；
   H = LN(Σ α_i z_i)；域头/型号头读 H；
4. 语义匹配得分 S_c：类 c 的每个语义 token 找最匹配的区域 token、对语义
   token 取平均（"尾喷结构"绑定尾部区域的 token 级对应）；
5. 置信度自适应融合（语义专家专属）：w=σ(MLP₂→₁₆→₁[top₁logit, top₁−top₂])
   （输入 detach，仅 48 参数），logits=(1−w)·视觉+w·S。

**训练目标（最终统一配方）**：L = L_domain + L_class（逆频率加权）。
三阶段课程：S1 仅 Region 10 epoch → S2 +Scene+Text 15–20 → S3 15–20
（plateau=3 早停，判据=验证军机 Macro-F1；总预算 ≤50）。
优化：AdamW 分组 lr（塔 1e-5 / 其余 1e-4）、wd 0.05、cosine、warmup 3、
batch 16 类均衡采样、AMP、梯度裁剪、梯度检查点。
历史版本（审稿对照用）还含对比/间隔/属性三项损失，已证明无测试增益，
最终方法移除。

**训练增强（第三创新点，最终保留）**：
- 上下文扩展率随机化：e ~ U(0.15, 0.35)（基准 0.25）逐实体采样；
- 跨通道随机擦除：p=0.25，1 块 2%–15% 面积灰矩形，RGB 与掩码**同步置零**。
- 仅训练期生效，推理零开销。

## 2.4 关键实现细节（论文可复现性清单）

| 项 | 值 |
|---|---|
| 4 通道进 SigLIP2 | 冻结原 3 通道 patch-conv + **零初始化 1 通道卷积分支**相加（初始等价无掩码） |
| 语义知识库 | 114 类×6 有效 token（768 维）；属性矩阵 114×466（历史配方用） |
| 检测器 | YOLO11x：单类、30 epoch、batch 16、imgsz 640；RT-DETR-L：20 epoch、batch 24 |
| 实体匹配 | 类别无关、按置信度降序贪心一对一、IoU≥0.5；Entity R 分母=全部 GT |
| 单专家参数 | ≈1.05 亿（视觉塔 186.6M×2 计数含共享；实际前向约 207M） |
| 训练成本 | 单专家 ≈7.5 GPU·h；DEDF ≈22.5；峰值显存 ≈2.9 GB（3090） |
| 推理速度 | 检测 0.044 s/图；三专家识别 0.418 s/图；端到端 0.462 s/图 |

## 3.1 数据与协议

Kaggle Military Aircraft Detection Dataset：25,015 图 / 44,700 实例 / 114 类
（103 军 + 11 民），官方图像级划分 train 18,735 / val 4,611 / test 1,669 图

## 3.3 模态消融（单模型，三种子 mean±std / seed0）

| 配置 | Top-1 | Macro-F1 | vs R | p |
|---|---|---|---|---|
| R | 90.64 | 88.93 | — | — |

+1.03/+0.64/+0.46（全正）；RT/RST 增益不稳定（RT 出现负种子）；

**同监督 vs 完整配方**：RST 91.77 vs 91.14（p=0.17）、RT 90.97 vs 91.51
（p=0.28）、DEDF 93.50 vs 93.64（p=0.75）→ 三个额外损失项无一致增益，
最终方法删除（也回应审稿人"损失配置混淆归因"）。

## 3.6 DEDF 与增益来源归因（审稿人核心问题的回答）

**聚合阶梯（seed0，GT 框）**：

| 配置 | Top-1 | Macro-F1 | vs RS | p |
|---|---|---|---|---|
| R / RS / RT / RST（统一监督） | 90.64/91.67/90.97/91.77 | — | — | — |
| RS+RT | 92.67 | 90.75 | +1.00 | — |
| RT+RST | 93.00 | 91.66 | +1.33 | — |
| RS+RST | 93.24 | 92.28 | +1.57 | — |
| **DEDF 三专家** | **93.50** | **92.14** | **+1.83** | **<1e-6** |
| DEDF（完整配方） | 93.64 | 92.15 | +1.97 | 4e-7 |

**逐种子 DEDF（同种子三专家）**：93.64 / 93.34 / 92.74 → **93.24±0.46**；
对同种子 RS：+1.97/+2.23/+1.47（每个 p<0.001）。

**等模型数对照（3 vs 3，回答"是不是普通集成"）**：

| 3 模型集成 | Top-1 | DEDF(s0) 与其差 | p |
|---|---|---|---|
| 3×R（Region Only） | 92.74 | **+0.90** | **0.009** |
| 3×RST（完整） | 93.00 | **+0.63** | **0.034** |
| 3×RT | 93.14 | +0.50 | 0.115 |
| **3×RS（最强单模型）** | **93.30** | +0.33 | 0.343 |
| DEDF（seed0） | 93.64 | — | — |

**结论（论文口径）**：DEDF 显著优于"重复弱配置/完整配置"的种子集成，
但与"重复最强单模型 RS"统计等价——决策级融合的主要收益来自集成多样性，
模态异质性的净增益需要在更大规模下才显现：

| 规模 | 配置 | Top-1 | vs 同规模对照 |
|---|---|---|---|
| 9 模型异构（3 种子×3 专家） | DEDF9 | **93.97** | vs 3×RS +0.67（p=0.019，9v3） |

其他归因对照：同监督 DEDF 93.17 仍 +2.13（p<1e-8）→ 非监督差异；
宽融合头（h=1536）90.77（−0.90）→ 非容量；温度缩放 93.14 / 学习权重
93.07 < 等权 93.54 → 非校准/拟合；专家两两分歧率 8.8–9.6%、oracle 95.6%
（种子集成 95.8%，多样性相当）。

分层（统一 RO margin 三分位）：DEDF 在低置信子集 **+9.09（p<1e-5）**（vs RO），
但种子集成同样 +4.40；DEDF 相对种子集成仅 +1.10（p=0.29）→ 低置信增益
亦非异质性独有。

## 4.3 结论

1. 跨域泛化成立：地面照片→遥感，16 类 Top-1 92.40%、Macro-F1 93.75%，
