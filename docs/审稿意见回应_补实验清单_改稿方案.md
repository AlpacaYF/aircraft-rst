## 一、结论先行

**审稿人的判断基本成立。** 当前版本的核心问题是：把统计上不显著的差值
（RST 比 RS 低 0.53 点，p=0.286）当作机制证据，并把 DEDF 的增益全部归因于
模态异质性。修回稿必须做三件事：

1. **补多种子**（RS / RT_adapt / RST_f × seed 1,2，共 6 个 run）——这是唯一
   无法用现有数据替代的实验；同时它直接构成审稿人要求的 seed-ensemble 对照。
2. **补归因对照**（同监督三专家 3 个 run + 干净的自适应对照 1 个 run）。
3. **重写立论**：删去“共享表示下相互制约”的机制断言，改为“三模态联合未观察
   到增益叠加（差值未达显著）”；DEDF 定位为“模态与监督配置异质、经验上更稳
   健的决策融合”，并如实报告异质性相对 seed 集成的净贡献。

其余 6 条主要问题（子机制消融、可复现性、数据一致性、新颖性定位、效率、
单数据集）大部分可以**零成本**用已有 dump 重算 + 补写完成；单数据集问题用
“去重审计 + 多种子 + 分层测试 + 局限声明”替代 5 折与跨库训练。

**最小可行动补实验集：13 个 run，约 100 GPU·h，4×3090 上约 3.5 天。**
（6 seed + 3 同监督 + 2 增广拆分 + 1 干净自适应对照 + 1 宽融合头；
另有 TTA、去重、分组表等零成本或推理级操作。）

## 三、8 条主要问题逐条回应

### 问题 1：核心动机的统计支撑不足（最关键）

**审稿人说得对。** 0.53 与 0.74 都低于论文自设的 1 点阈值；正文未印任何 p 值；
McNemar 不能替代训练方差。

**现有证据**：p 值全部存在（见 2.1）。RST<RS 不显著（0.286）；同监督 RST
仅低 0.13（p=0.832）；DEDF 对 RS 极显著，对最强双专家 +0.73（p=0.0046）。

**必须补的实验**：seed 1,2 × {RS, RT_adapt, RST_f}（6 runs）。
产出：各配置 mean±std、三种子下的 Δ 稳定性、seed-ensemble 对照。

**改稿**：
- 4.2.1：把"极差约 2 点、<1 点不作结论"改为"报告 3 个种子的 mean±std，并以
  逐实体 McNemar 检验判断差异显著性；对 <1 点但显著的差异（DEDF vs 最强双
  专家 +0.73，p=0.005）如实报告并讨论其实际意义"。
- 3.4.1 与 4.4.2：删除"相互制约/梯度竞争"的确定语气，改为"三模态联合未观察
  到增益叠加（同监督条件下差值 0.13，p=0.83；完整配方下 −0.53，p=0.29）；
  单模型层面无法同时兑现两类互补机制，我们将其作为 DEDF 的设计动机，并在
  4.4.3 用独立专家聚合验证"。
- 4.4.3：DEDF 的 +1.97（p<1e-4）与 +0.73（p=0.005）全部标注检验结果。
- 摘要/结论：不再出现"证明/稳定"等强断言，改为"在本数据集与 3 个随机种子下"。

### 问题 2：DEDF 增益来源存在替代解释

**审稿人说得对。** 3 倍算力、损失配置不同、等权隐含尺度一致，三项都需对照。

**现有证据**（零成本，见 2.4）：ECE 6.1–7.2%；温度缩放与学习权重都没有超过
等权 logit（93.14/93.07 vs 93.54）；oracle 95.64；分歧率约 9%。

**必须补的实验**：
1. **seed-ensemble 对照**：用 seed 0/1/2 的 RS 三模型做同模态 logit 平均，
   与 DEDF 比较——这是决定性对照。
2. **同监督三专家**（3 runs）：RS/RT/RST 均只用域+分类损失
   （`--lambda-con 0 --no-use-hard-negative --no-use-diff-loss`），再聚合。
   这样"模态异质性"的归因才干净。
3. **算力匹配**（择一）：(a) RS 的 3 尺度 TTA（推理成本=3 倍，零训练）；
   (b) RST 宽融合头（h=1024，1 run）。建议两个都做，(a) 成本最低。

**改稿**：
- 3.4.2 删除"训练配方的一致则保证贡献处于同一量纲"——实际损失配置不同。
  改为"优化器与训练预算一致；损失项按专家职能配置。为排除监督差异的影响，
  4.4.3 补充了同监督对照"。
- 3.4.3 与 4.4.3 明确写"DEDF 是模态与监督配置异质的决策集成；其增益 = 集成
  多样性 + 异质互补，本文量化后者"。
- 新增小节"4.4.3.2 增益来源分析"：ECE/温度/学习权重/seed-ensemble/同监督/
  TTA 六项对照，一张表。
- 若 seed-ensemble 也达到 ~92.5，则把 DEDF 的增益表述为"在种子多样性之上，
  异质性再贡献约 X 点"，创新点②相应降级为"融合范式贡献"。
