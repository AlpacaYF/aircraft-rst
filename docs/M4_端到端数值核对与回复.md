## 一、一句话结论

审稿人**指出的现象成立**（4.4.5 的三段百分比不能相加、RT-DETR 三行预测数不同），
但**具体归因有两处算错**：89.51% 属于 YOLO+RST 而不是 Swin-B；matched 不是
2771 而是 2573（YOLO）/2657（RT-DETR）。真正需要修的是三件事：

1. 正文的"84.4% + 7.9% + 7.7%"不是合法分解——7.9% 是 `(n_pred−TP_e)/G_d`
   （含重复框与背景误检），7.7% 是 `1−检测F1`，两者都不是"型号误判"与"漏检"；
2. **RT-DETR+Swin-B 用了 0.25 阈值**（4067 框），RST/DEDF 用 0.5（2902 框），
   表格未标注，导致三行预测数 4068/2946/2946 的假象；
3. **R 的分母实际是"有检测图的 GT"**（YOLO 2899、RT-DETR 2957），
   不是 4.2.2 声明的全部 3002；103/45 个零检测图 GT 被漏出分母。

## 二、指标定义（按代码）

- 检测匹配：类别无关、逐图按检测置信度降序、贪心一对一，IoU≥0.5；
  预测匹配不到记为 FP_d，未被认领的 GT 记为 FN_d。
- 实体匹配：同一 IoU/贪心规则，但使用**独立的认领集合**；预测 IoU≥0.5 且
  类别等于该 GT 的类时记 TP_e。因此 `recognition_top1_given_match =
  TP_e / TP_d`，严格说是"IoU 匹配预测中型号正确的比例"；由于认领集合独立，
  理论上一个重复框也可能贡献 TP_e（本表 TP_e<TP_d，未发生越界，但建议统一
  认领集合并把定义写清）。
- 重复框：最优 IoU≥0.5 但该 GT 已被更高分框认领 → 记 FP（与背景误检分开统计）。
- 零检测图：没有任何检测框的图像；其 GT 当前不计入 R 的分母（需修）。

## 四、正文的分段百分比错在哪

以 YOLO+DEDF 为例（G_d=2899 口径），正确的三分：
- 正确：2447/2899 = 84.41%
- 型号误判：126/2899 = 4.35%
- 未检出（G_d 内）：326/2899 = 11.25%
- 另有 103 个零检测图 GT（3.55%）不在该分母内。

正文的 7.9% 实际是 `(2675−2447)/2899 = 7.86%`，即 FP_e/G_d，包含：
11 个重复框 + 91 个背景误检 + 126 个型号误判，并非"型号误判"。
正文的 7.7% 实际是 `1−检测F1 = 1−0.9232 = 7.68%`，与漏检率无关（真实漏检
11.25% 或 14.29%）。因此 84.4+7.9+7.7 只是三个不同分母/定义的数拼在一起。

Swin-B 的 22.4% 同理：`(2675−2026)/2899 = 22.39%`，含 102 个重复/背景误检；
真实型号误判是 18.87%。

**自洽性验证**：95.10% = 2447/2573 = 84.41/(84.41+4.35) ✓；
89.51% = 2303/2573 ✓；94.88% = 2521/2657 ✓；88.82% = 2360/2657 ✓。
所以识别准确率本身是对的，错的是正文的分解。

## 五、审稿人反推为何不同

- 89.51% 属于 **YOLO+RST**，不是 Swin-B；Swin-B 的 clsAcc 是 **78.74%**。
- 94.88% 属于 **RT-DETR+DEDF**，95.10% 属于 **YOLO+DEDF**。
- 反推的 2344/2513/2665 是把这三列交叉套用的结果；正确的 matched 是
  YOLO 2573、RT-DETR 2657（三分类器相同）。
- 2770 不是预测数：它等于 `TP_e/P`（用 TP_e 配 G_d 口径的 P），是分母混用
  的产物；真实 n_pred 是 2675（YOLO，0.5）/2902（RT-DETR，0.5）。
- 4068/2946/2946 的差异来自阈值：RT-DETR+Swin-B 是 0.25（4067 框），
  RST/DEDF 是 0.5（2902 框）。统一 0.5 后三行预测数一致。
