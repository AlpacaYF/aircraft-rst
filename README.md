# RST-DEDF: Region–Scene–Text multimodal fusion for aircraft entity recognition

Code and experiment artifacts for fine-grained military aircraft entity
extraction (114 classes, 103 military) with an RST multimodal fusion model and
DEDF (decoupled-expert decision fusion).

## What is here

| Path | Content |
|---|---|
| `rst/` | Model code: config, model, losses, train, eval, entity extraction |
| `tools/` | Experiment scripts (detection, evaluation, batch runners, MAR20 cross-dataset eval) |
| `scripts/` | Dataset index building (crop geometry, scene tiling plan) |
| `deploy/` | Single-image end-to-end demo (YOLO11x + 3-expert DEDF) + manifest |
| `figures/` | Paper figures |
| `knowledge/` | Offline semantic knowledge base (CLIP-encoded class prototypes) |
| `index/` | Dataset index (instances.jsonl, class_meta.json, hard_table) |
| `docs/` | Experiment summaries, paper drafts, analysis reports (Chinese) |
| `requirements.txt`, `setup.sh`, `run_*.sh` | Environment and entry points |

## Not in this repo (too large / regenerable)

- `dataset/` — 25,015 raw images: Kaggle
  [Military Aircraft Detection Dataset](https://www.kaggle.com/datasets/a2015003713/militaryaircraftdetectiondataset)
- `crop/` — per-class region crops, regenerated by `scripts/build_dataset_index.py`
- `.cache/`, `cache/` — HuggingFace weights
  (`google/siglip2-base-patch16-384`) and scene-token cache, downloaded on first run
- `runs/` — training checkpoints (~5.6 GB per run), see `docs/` for all metrics

## Quick start (on the lab server)

```bash
git clone <this-repo> ~/dmt/aircraft_rst_git
cd ~/dmt/aircraft_rst_git
# link or copy dataset/ from your data location, then:
bash setup.sh          # creates .venv and .venv-det inside the project
source env.sh          # only if you use the original env.sh layout
bash run_train.sh      # trains the three experts (uniform supervision)
```

Deploy demo (single image → entities):

```bash
.venv/bin/python deploy/demo.py --image <photo.jpg> --outdir deploy/output/demo --recipe uniform
```

## Main results (test split, 3,002 entities)

| Task | Metric | Value |
|---|---|---|
| Fine-grained classification (GT boxes) | DEDF Top-1 / Macro-F1 | 93.50 / 92.14 % |
| End-to-end entity extraction (YOLO11x+DEDF) | Entity F1 | 86.21 % |
| Inference speed | end-to-end | 0.462 s/image |
| MAR20 cross-dataset (16 mapped classes, zero retraining) | GT-box Top-1 | 92.40 % |

See `docs/` for full experiment reports, statistics (mean±std over 3 seeds,
McNemar paired tests) and the analysis of DEDF's gain sources.

## Citation / data

Dataset: Kaggle Military Aircraft Detection Dataset (114 classes).
Cross-dataset benchmark: MAR20 (remote sensing, 20 classes).
